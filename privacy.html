개인정보 처리방침

최종 업데이트: 2026년 11월 18일

꼽주머니(Kkop-jumoney, 이하 "앱")는 사용자의 개인 가계부 기능을 제공하기 위해 아래와 같이 개인정보를 처리합니다. 앱은 사용자가 직접 연결한 금융 데이터만을 사용하며, 가계부·예산 관리 외의 목적으로 이용하지 않습니다.

1. 수집하는 정보

  • 금융 거래 정보 — 사용자가 Plaid를 통해 연결한 계좌의 거래 내역(금액, 날짜, 가맹점명, 카테고리, 계좌 유형 등).
  • 계정 정보 — 로그인 식별자(예: Google 로그인 시 제공되는 식별 정보), 닉네임, 인증 토큰.
  • 사용자 입력 정보 — 직접 추가한 거래, 설정한 목표·예산, 메모.

앱은 은행 로그인 자격 증명(아이디·비밀번호)을 직접 저장하거나 열람하지 않습니다. 은행 인증은 전적으로 Plaid를 통해 처리됩니다.

2. 정보의 이용 목적

  • 거래 내역 동기화 및 카테고리 자동 분류
  • 목표·예산 관리와 소비 리포트 제공
  • 캐릭터·알림 등 앱 기능 제공 및 사용자 인증

3. Plaid를 통한 금융 데이터 연동

앱은 금융 계좌 연결 및 거래 내역 조회를 위해 Plaid Inc.의 서비스를 사용합니다. 사용자가 계좌를 연결하면 Plaid가 해당 금융기관으로부터 데이터를 안전하게 가져와 앱에 전달합니다. Plaid의 개인정보 처리방침은 plaid.com/legal 에서 확인할 수 있습니다.

4. 보관 및 보안

  • 거래·계정 데이터는 앱 서버의 데이터베이스에 저장됩니다.
  • Plaid 액세스 토큰은 암호화하여 저장합니다.
  • API 요청은 사용자별 인증 토큰(JWT)으로 보호됩니다.

5. 제3자 제공

앱은 사용자의 개인정보를 판매하지 않으며, 광고 목적으로 공유하지 않습니다. 데이터는 서비스 운영에 필요한 범위(예: 금융 데이터 연동을 위한 Plaid, 서버 호스팅)에서만 처리됩니다.

6. 사용자의 권리

  • 언제든지 앱 설정에서 연결된 은행 계좌를 해제할 수 있습니다.
  • 계정 및 관련 데이터의 삭제를 요청할 수 있으며, 요청 시 저장된 거래·계정 정보가 삭제됩니다.
